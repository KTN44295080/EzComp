# 自動接地・なじませ

キャンバス左上の「接地・なじませ」を開き、人物を選んで「選択を自動接地」。
「表示中をまとめて」は、表示されている透過素材のうち確度の高い候補だけを処理する。
非表示／ロック中／不透明な背景／合成用の光や影は対象外。曖昧な候補は要確認として表示する。
手動アンカーを設定したレイヤーは一括処理で上書きしない。

## 仕上がり

- 自然な接地：選択した床の画像と既存の色補正から、影の色を推定する。
- 幻想的な水色：広い影をスクリーン合成し、水色のにじみを足す。
- 暖色の影：暖かい色の乗算影。

どの設定でも靴底の狭い接触影は乗算の別成分として残す。AOは足元に限定した
楕円状の近似であり、全身の輪郭を暗く囲うものでも、3DのAOでもない。
床色の反射は元画像のアルファ内、接地点付近にだけ重ねる。
元絵の画素・既存色補正は書き換えない。

## 微調整

「接地点を表示・ドラッグ」で丸いマーカーを靴底へ移動できる。マーカーを選び
矢印キーで1px、Shift+矢印で10px調整。詳細では接地点の追加・削除・幅・接地率を変更する。
上がっている足の接地率を0%にすると、その足の効果を止める。
床の傾き、AO、影の広がり・柔らかさ、影色・合成モード、にじみ、反射色も個別調整可能。

## 保存と互換性

設定は各レイヤーの省略可能な `grounding` フィールドに保存する。
`.ezcomp` / IndexedDB / Undo・Redo / 複製は既存のレイヤー保存機構を使う。
旧ファイルは自動で有効化しない。無効時の元の描画経路はそのまま。
有効なレイヤーでは旧式の下端中央の接地影・全周AOを描画時だけ置き換える。
無効に戻すと保存されていた旧値が復活する。別レイヤーに描かれた既存影は自動で削除しない。
Before比較では新しい効果もオフになる。Reset allでも解除する。

描画専用の派生画像は一時レジストリーに置き、元レイヤーや保存ファイルに追加しない。
プレビューとPNG/PDF/AIの既存書き出しで同じ前処理を通す。新たな依存ライブラリや
画像アップロード、D1、R2、外部DBは追加していない。

## 推定の限界

アルファ輪郭の下端を解析する2Dヒューリスティックで、足を意味的に認識するAIではない。
長い裾・垂れた髪・足が切れた画像や斜面では手動確認が必要。床レイヤーのアルファで
効果範囲を制限するが、床と壁を自動で意味分割しない。色を塗った影だけで
元絵のポーズや不適切な配置を修正できるわけではない。

## 公開

既存の `.openai/hosting.json`、Site ID、依存関係、公開先を変更しない。
GitHubへのコード反映とChatGPT Sitesの再公開は別工程。Sitesの再公開操作が可能な
環境から、検証済みコミットを既存EzCompのSiteへ反映する必要がある。
